# 多语言（中文、英文、西班牙语）

ming 2026-11-23 要的。Notion 卡片「多语言版本：中文、英文、西班牙语」。

## 怎么做的

- 代码里照旧写中文，外面包一层 `tr("…")`。带值的句子直接写 `tr("够花 \(n) 个月")`，表里的键是 `够花 %@ 个月`。
- 英文、西班牙语在 `Sources/FinanceCore/L10n/L10n+en.swift`、`L10n+es.swift`，按中文原文查。译文里要换顺序写 `%1$@`、`%2$@`。
- 表里没有的显示中文原文，所以可以一页一页翻。
- 运行时才知道的中文（枚举原始值）用 `trKey(x)`。
- 语言在「设置 → 隐私与外观 → 语言」里选，存在 UserDefaults `xiaxia.language`，换了马上生效。
- 没选过语言的人现在默认中文（`L10n.fallbackChoice`）。**全部翻完后**改成 `.system`（跟随系统；系统不是中/英/西就用英文）。

没用苹果的 String Catalog：界面在 Swift 包里，`swift build` 不编译 .xcstrings，fin 和测试也读不到；自己的表三处是同一份，还能不重开 app 就切换。

## 规矩

1. 新加界面文字：包 `tr`，同时在两张表各加一行。`swift test` 会查两张表的键一样、`%@` 个数一样。
2. `python3 scripts/l10n-scan.py` 看进度；`--list` 列出包了 tr 但表里没有的键（有就返回 1）。
3. 不翻的：给 AI 的提示词和 skill、`fin` 的输出、示例账本的数据、存进账本的东西（分类名、改动记录）、`AppSection.rawValue` 这类当标识用的中文。
4. 金额格式不变（`1.234,56 €`）。日期用 `L10n.language.locale`。
5. 夏夏的 AI 回话跟着用户说的语言走，不在表里。
