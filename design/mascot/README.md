# 夏夏和 AI 伙伴的形象

四个原创 Q 版角色，2026-11-22 用 ChatGPT 生图按文字描述画的（参考了网上「AI 拟人」这一类画风的感觉，没有照抄任何一张图，也没有任何官方 logo）：

| 角色 | 是谁 | 在 app 里出现的地方 |
|---|---|---|
| 夏夏 xiaxia | 主角，蓝发鲸鱼娘，女仆水手裙，抱小算盘 | 每页「夏夏说」卡片、空状态（打盹 / 担心 / 庆祝…）、设置里选性格、对话栏 |
| 小橘 orange | 橘发书本少女，Claude 系的伙伴 | AI 连接状态、「Claude 刚记了 N 笔」、对话栏里 Claude Code 在帮忙时 |
| 小紫 lilac | 小龙角少女，Codex / GPT 的伙伴 | 同上（Codex） |
| 小星 star | 星空少女，Gemini、Hermes 和其它 AI 的伙伴 | 同上（Gemini CLI、Hermes、Cursor…） |

## 男生版

2026-11-23 加了一套男生版（同样四个角色、同样画风，ming 说男女最好各一套）。文件名多一个 `-boy`：`xiaxia-boy-idle.webp`、`orange-boy-talk.webp`……设置里「夏夏的性格」上方有「女生 / 男生」切换（存在 `mascotLook`），男生版缺的图自动用女生版。

## 生意版（成年秘书）

2026-11-25 加。生意模式（看生意那边）时，四个角色换成成年人的秘书 / 文员形象：同样的发色、代表色和标志物（鲸鱼耳和尾巴、书、龙角、星星），衬衫、马甲、长裤。画风是 ming 从三种样稿里选的「柔和水彩」。生活模式的图不动。

- 文件名多一个 `-biz`：`xiaxia-biz-idle.webp`、`orange-biz-think.webp`……男生生意版以后叫 `xiaxia-biz-boy-*`。
- 动作和生活版一样（夏夏 12 个，伙伴 4 个）。眨眼、说话帧是和待机图同一姿势的整张图（只差眼睛或嘴），直接当 `-blink` / `-talk` 用，不用 patch.py。
- 缺图时按这个顺序找：生意男生版 → 男生生活版 → 生意女生版 → 生活女生版（`MascotImages.candidates`），所以可以一批一批加。某个动作缺了，退回同一套的待机图，不混画风。
- 界面上由 `.environment(\.mascotBusiness, true)` 打开（生意模式的界面接好后由外层设置）。
- 全身图里脸小：`build.py` 遇到名字带 `-biz` 的图，只在图上部 30% 找脸，头像框边长 0.21。
- 原图（1400×1400 透明 PNG）在 OpenBot 共享文件夹 `xiaxia-business/mascot-biz/`，不进仓库。

## 动作

文件名是 `角色-动作.webp`，放在 `Sources/LedgerUI/Resources/Mascot/`。缺了的动作自动退回 `-idle`，加图就生效。

- 夏夏：idle（待机）、blink（眨眼帧）、talk（说话帧）、calm（文静）、cheer（打气）、sharp（毒舌）、think（在想）、write（记账）、worried（钱花超了）、celebrate（存钱成功）、sleep（睡着）、hello（打招呼）
- 伙伴：idle、blink、talk、think

四种性格：温和直说 = idle，毒舌 = sharp，文静 = calm，打气 = cheer。

## 怎么动

`MascotView`（Sources/LedgerUI/Mascot.swift）在 SwiftUI 里实时动：呼吸（上下轻微伸缩）、左右摆、开心的动作会蹦、担心会抖；每 3.7 秒眨一次眼；说话时嘴一张一合；身边飘星星、金币、汗珠、Zzz、泡泡。打开系统「减弱动态效果」就全部停下。

眨眼和说话帧不是整张换：ChatGPT 每次重画整张图会有细微偏差，所以用 `patch.py` 只把闭眼 / 张嘴那一小块（羽化的椭圆）贴回定稿图，换帧时身体纹丝不动。

## 重新生成

1. 原图（ChatGPT 下载的 1254×1254 透明 PNG）在项目文件夹 `mascot/raw/`，不进仓库。
2. 眨眼 / 说话（这次用的椭圆：夏夏眨眼 380 345 790 610、说话 530 530 700 640；小橘 370 370 815 625 / 555 555 715 645；小星 355 370 775 620 / 380 410 730 665；小紫 385 345 815 600 / 565 550 705 625，羽化都是 10；男生版：夏夏比较特别，定稿和后面的动作衣服不一致，所以用「说话」原图当底，贴上眨眼图的嘴（555 475 715 590）当待机，再贴眼睛（420 360 830 570）当眨眼，小橘 410 350 830 560 / 535 465 690 585，小紫 430 360 820 550 / 560 480 700 600，小星 395 350 835 600（羽化 6）/ 570 520 720 640）：`python3 design/mascot/patch.py 定稿.png 闭眼图.png 输出.png x0 y0 x1 y1 [羽化]`，坐标是眼睛（或嘴）那块的椭圆范围。
3. 全部放进一个文件夹（命名同上），`python3 design/mascot/build.py 那个文件夹`：缩成 640px WebP，并算这些图的脸部位置（写进 `MascotData.swift`；别的图原来的位置照旧留着，可以只放这次新加的图）。
4. 自动找脸偶尔会找错（比如庆祝图里的粉色存钱罐），在 build.py 的 `OVERRIDES` 里手动写位置。
