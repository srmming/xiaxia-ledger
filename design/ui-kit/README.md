# UI 套件 v1（2026-11-21）

夏夏账本改成「财务看板」后的整套设计：定位、9 个页面各回答什么问题、设计规范、组件、Mac 和 iPhone 全部页面、各种状态。

- 在线看：https://claude.ai/artifact/2oKLRn5LUCRsDH1rNGa7UJ （ming 分享后别人才能打开）
- `index.html`：可直接在浏览器打开的完整展示页（已内嵌图标）。
- `template.html`：源文件，图标位置是 `__ICONS__`，由 `../icons/` 下的 SVG 生成。
- 页面里的金额、商户、人名全是编造的示例。

要点：app 主角是「看」；导入、分类、借款、目标等交给 AI（MCP / fin）；保留极简「记一笔」（Mac 工具栏 ⌘N、iPhone 右上角 +），记下的标「你」、进改动记录；AI 意见由 AI 写进账本，app 展示；靛蓝 = AI，晨光橙 = 品牌主色。
